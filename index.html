// FAQ

Questions

Quick answers.

Is Print Me really free?

Yes. It is free to download and use, with no ads and no sign-up.

Why does Windows say “Unknown publisher”?

Print Me is a small independent app and is not digitally signed (signing certificates cost money). Windows shows this warning for most unsigned apps. Click More info → Run anyway to continue.

My antivirus says it’s suspicious. What should I do?

New, unsigned apps are sometimes flagged by mistake (a “false positive”). You can check the file yourself on virustotal.com, and install it only if you’re comfortable. Please don’t switch your antivirus off. If it blocks the file, you can allow just this one file.

Do my files get uploaded anywhere?

No. Print Me works completely on your computer. Your images and PDFs are never uploaded. The only internet connection is an optional update check, which just asks GitHub for the latest version number. You can turn it off in Settings.

How do I update Print Me?

Open Settings → Updates → Check for updates now. A green “Update available” button also appears in the app by itself when a new version is out. Or simply download the newest installer from this page and run it.

Which printers does it work with?

Any printer installed in Windows. You can also use “Save as PDF” if you don’t have a printer connected.

Does it work on Mac or Linux?

Not yet. Print Me is for Windows 10 and 11 (64-bit) only.

How do I uninstall it?

Go to Windows Settings → Apps, find Print Me and click Uninstall. If you used the portable .exe, just delete the file.
